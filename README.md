## Current product direction

Cultivator is being positioned as a **closed-loop oxygen assurance and aeration-intelligence system for shrimp farms**.

Core loop:

> **Sense → Predict → Act → Verify**

Current strategy:
- Current sensing per aerator
- Dissolved-oxygen sensing at pond level
- Safe local aerator control
- Verification that a commanded aerator actually responded
- AI for DO forecasting, electrical anomaly detection, and aeration optimization

Vibration sensing is intentionally excluded from the current product direction.

## Core commercial model used in the report

These are **strategy assumptions**, not signed customer terms.

- Pond Core + optical DO: **NT$24,900 / pond**
- Aerator Node: **NT$6,900 / aerator**
- Cultivator Pro: **NT$1,490 / pond / month**
- Example 6-aerator pond: **NT$66,300 hardware**

The report explains the value-based rationale and benchmarks it against publicly reported HydroNeo energy-savings results.
